# Miting Geeko Unified

این ریپوزیتوری نسخه‌ی یکپارچه‌شده‌ی پروژه `local-meeting-app-nf` است که ظاهر و تجربه کاربری آن با نسخه مرجع موجود در `gg.zip` همسان‌سازی شده است.

## ساختار
- `local-meeting-app-nf/`: اپلیکیشن کامل (سرور + رابط کاربری)

## اجرا
```bash
cd local-meeting-app-nf
npm install
npm start
```

سپس روی آدرس پیش‌فرض پروژه (طبق خروجی ترمینال) اجرا کنید.
